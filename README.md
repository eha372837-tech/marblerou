# Marble Roulette — 바로 실행

## 실행

프로젝트 루트에서 실행합니다.

```bash
npm start
```

기본 포트는 `4173`이며, 다른 포트를 쓰려면 `PORT=8080 npm start`처럼 지정할 수 있습니다. 브라우저에서 `/` 또는 `/roulette/`으로 룰렛을 열고 `/admin/`에서 참가자와 연출 모드를 설정합니다.

## 연출 모드

관리자 패널에서 **첫 번째로 들어갈 공**으로 참가자를 지정한 뒤 **연출 모드 — 첫 공 부드러운 120% · 장애물 통과 없음 · 반동 제거**를 켭니다. 선택한 공 하나의 목표 속도를 나머지 참가 공들의 중앙 이동 속도의 1.2배로 부드럽게 맞춥니다. 선택 공의 수직 위치는 뒤로(위쪽으로) 되돌아가지 않게 제한하고, 위쪽 속도는 0으로 잘라 아래 방향으로만 진행하게 합니다. 장애물 통과 확률은 적용하지 않으며 모든 장애물을 고체로 만들고 빠른 구슬의 연속 충돌 검사를 켭니다. 폴리라인 꼭짓점에는 작은 물리 캡을 추가하고, 장애물 접촉 중에는 하강 제한이 위치를 강제로 이동시키지 않도록 합니다. 충돌로 제거되던 장애물도 계속 남도록 했습니다. 선택 공은 장애물과 접촉할 때 표면 마찰을 0으로 낮춰 달라붙지 않고 미끄러지도록 하고, 구슬·장애물·외곽벽과 실제 접촉하면 충돌면 법선 방향의 상대 속도를 0으로 맞춰 반동을 없앱니다. 첫 공 지정을 비워 두면 보정은 적용되지 않습니다.

설정은 같은 브라우저의 `localStorage`를 사용하므로 룰렛과 관리자 페이지를 같은 브라우저에서 열어야 합니다. 물리 시뮬레이션 특성상 특정 공의 도착 순서는 보장되지 않습니다.

## 포함 내용

- Box2D/WASM 및 이미지 자산을 포함한 정적 사이트
- `npm start` 실행 설정
- 별도 `/admin/` 참가자·입장 순서·연출 모드 패널
- 관리자 지정 공의 부드러운 1.2배 목표 속도·단조 하강, 장애물 통과 제거, 장애물 접촉 마찰 0, 충돌 반동 제거, 브라우저 캐시 버전 갱신
