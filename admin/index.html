관리자 패널

룰렛 참가자와 공의 입장 순서를 관리합니다. 저장한 설정은 같은 브라우저의 룰렛 화면에 즉시 적용됩니다.

예: 홍길동, 김철수*2, 이영희/2

관리자 패널에서 첫 입장 공으로 지정한 공만 다른 공들의 중앙 이동 속도를 기준으로 1.2배 목표 속도에 부드럽게 맞춥니다. 선택된 공은 위로 되튀지 않고 아래로만 진행하며, 장애물은 생성 시부터 고체로 처리하며 빠른 공의 연속 충돌 검사도 켭니다. 충돌로 장애물이 삭제되지 않습니다. 장애물 접촉 마찰을 0으로 낮춰 표면에 달라붙지 않고 미끄러지게 하고, 구슬·장애물·외곽벽 충돌 반동도 제거합니다. 첫 공 지정이 비어 있으면 보정은 적용되지 않으며, 도착 순서는 보장되지 않습니다.
